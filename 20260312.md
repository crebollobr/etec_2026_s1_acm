## Administração de Sistemas: Filtros, Estrutura de Diretórios e Disco

Nesta aula, exploramos as ferramentas essenciais para manipular arquivos, entender a hierarquia do sistema Linux e gerenciar o armazenamento.

---

### 1. Filtros e Manipulação de Texto

Estes comandos são fundamentais para encontrar informações rapidamente em arquivos de log ou configurações.

* **`find`**: Pesquisa arquivos no diretório baseado em critérios (nome, data, tamanho).
* *Exemplo:* `find /home -name "projeto.txt"` (Busca o arquivo pelo nome dentro de /home).


* **`head`**: Exibe as primeiras linhas de um arquivo (padrão: 10 linhas).
* *Exemplo:* `head -n 5 lista.txt` (Mostra as 5 primeiras linhas).


* **`tail`**: Exibe as últimas linhas de um arquivo. Muito usado para logs com a opção `-f`.
* *Exemplo:* `tail -f /var/log/syslog` (Monitora o log em tempo real).


* **`diff`**: Compara o conteúdo de dois arquivos e mostra as diferenças.
* *Exemplo:* `diff arquivo1.txt arquivo2.txt`.



### 2. Empacotamento e Montagem

* **`tar`**: Agrupa vários arquivos em um só (comum para backups). Não confunda com compactação (zip), embora possa ser usado junto (ex: .tar.gz).
* *Exemplo:* `tar -cvf backup.tar /var/www` (Cria um pacote do diretório www).


* **`mount` / `umount**`: Conecta ou desconecta dispositivos físicos (pendrives, discos) à estrutura de diretórios do Linux.
* *Exemplo:* `mount /dev/sdb1 /mnt/pendrive`.



---

### 3. Estrutura de Diretórios (FHS)

No Linux, tudo começa na raiz `/`. Abaixo, os principais diretórios:

| Diretório | Descrição |
| --- | --- |
| `/bin` | Binários essenciais do sistema (comandos como ls, cd). |
| `/boot` | Arquivos de inicialização (Kernel, Grub). |
| `/dev` | Arquivos de dispositivos (hardware como discos, teclado). |
| `/etc` | Arquivos de configuração do sistema. |
| `/home` | Pastas pessoais dos usuários comuns. |
| `/root` | Pasta pessoal do superusuário (administrador). |
| `/tmp` | Arquivos temporários (apagados ao reiniciar). |
| `/var` | Arquivos variáveis (Logs, bancos de dados, cache). |
| `/proc` | Informações do sistema e processos em tempo real (diretório virtual). |

---

### 4. Gerenciamento de Disco

Comandos para monitorar o espaço ocupado:

* **`df -h`**: Mostra o espaço livre/ocupado em cada partição do disco (formato legível).
* **`du -sh`**: Mostra o tamanho total de um diretório específico.

---

### Exercício Prático

1. **Pesquisa:** Use o comando `find` para localizar todos os arquivos que terminam com `.log` dentro do diretório `/var`.
2. **Monitoramento:** Use o `tail` para visualizar as últimas 20 linhas do arquivo `/var/log/auth.log`.
3. **Análise de Espaço:** Verifique qual o tamanho total da sua pasta `/home` utilizando o comando `du`.
4. **Comparação:** Crie dois arquivos de texto simples, altere uma palavra em um deles e use o `diff` para ver o resultado.
5. **Desafio:** Crie um pacote `.tar` chamado `meu_backup.tar` contendo todos os arquivos da sua pasta de documentos.

---

> **Dica de Ouro:** No Linux, o diretório `/etc` é o "Painel de Controle". Quase toda configuração do sistema é um arquivo de texto dentro desta pasta.
