## 1. A Árvore de Diretórios (FHS)

No Linux, tudo começa na raiz `/`. Diferente do Windows (`C:\`), o Linux organiza tudo de forma centralizada e padronizada pelo *Filesystem Hierarchy Standard*.

### 📂 Diretórios de Sistema e Binários

| Diretório | Descrição |
| --- | --- |
| `/bin` | Binários essenciais do sistema (comandos básicos como `ls`, `cp`). |
| `/boot` | Arquivos de inicialização (Kernel, GRUB). |
| `/lib` | Bibliotecas essenciais para os binários em `/bin` e `/sbin`. |
| `/usr` | Programas e arquivos de leitura do usuário (maior parte do sistema). |
| `/opt` | Pacotes de software opcionais (instalações externas como Google Chrome). |

### ⚙️ Configuração e Processos

| Diretório | Descrição |
| --- | --- |
| `/etc` | **O coração do sistema.** Arquivos de configuração local. |
| `/proc` | Sistema de arquivos virtual com informações de processos e kernel. |
| `/sys` | Informações sobre dispositivos e drivers do sistema. |
| `/run` | Dados de execução do sistema desde o último boot. |

### 👤 Usuários e Dados

| Diretório | Descrição |
| --- | --- |
| `/home` | Pastas pessoais dos usuários comuns. |
| `/root` | Pasta pessoal do superusuário (Administrator). |
| `/tmp` | Arquivos temporários (geralmente apagados no reboot). |
| `/var` | Arquivos variáveis (Logs do sistema, bancos de dados, cache). |

### 🔌 Dispositivos e Montagem

| Diretório | Descrição |
| --- | --- |
| `/dev` | Arquivos de dispositivos (tudo é arquivo: HDs, Teclado, etc). |
| `/mnt` | Ponto de montagem temporário para sistemas de arquivos externos. |

## 2. Gerenciamento de Disco via Terminal

Comandos essenciais para monitorar o uso de armazenamento.

### 📊 Verificação de Espaço

* `df` (Disk Free): Exibe o espaço livre/ocupado nas partições.
* `df -h`: Formato "humano" (Gigas, Megas).


* `du` (Disk Usage): Mede o tamanho de diretórios e arquivos específicos.
* `du -sh /var`: Resumo do tamanho da pasta `/var`.



### 💾 Manipulação de Dispositivos

* `mount`: Conecta um sistema de arquivos (pendrive, HD externo) a um diretório.
* `umount`: Desconecta o dispositivo com segurança.
> **Nota:** Nunca remova um dispositivo sem dar `umount`, sob risco de corrupção de dados.

## 🛠️ Atividade Prática (Hands-on)

1. **Navegação:** Vá até o diretório `/etc` e liste os arquivos. Consegue encontrar o arquivo `passwd`?
2. **Monitoramento:** Execute `df -h`. Qual partição do seu sistema está mais cheia?
3. **Investigação:** Use o comando `du -sh /var/log`. Quanto espaço seus logs estão ocupando?
4. **Processos:** Entre em `/proc` e dê um `ls`. O que são os números que aparecem como nomes de pastas?
