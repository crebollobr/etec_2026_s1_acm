**Aula 01: Arquitetura Linux, Distribuições e Terminal | bash, history, man, echo, variáveis de ambiente.**

### 1. Arquitetura Linux e Distribuições

* **O Kernel:** É o coração do sistema, gerencia o hardware e a memória.
* **O Shell:** É o intérprete que recebe seus comandos (o **bash** é o padrão).
* **Distribuições:** São conjuntos que unem o Kernel + Interface + Gerenciador de Pacotes (Ex: Ubuntu, Debian, CentOS).

### 2. Comandos Básicos do Terminal

* **bash:** Inicia uma nova sessão do interpretador de comandos.
* **history:** Exibe a lista de comandos digitados anteriormente.
* *Exemplo:* `history 10` (mostra os últimos 10 comandos).


* **man:** Abre o manual de instruções de um comando.
* *Exemplo:* `man ls` (ensina como usar o comando de listar arquivos).

* **help:** Abre o help do bash.
* *Exemplo:* `help if`.

* **info:** O "irmão mais moderno" do man. Fornece manuais detalhados e navegáveis (como se fossem páginas web dentro do terminal).
* *Exemplo:* info coreutils

* **echo:** Imprime um texto ou o valor de uma variável na tela.
* *Exemplo:* `echo "Iniciando aula de Linux"`



### 3. Variáveis de Ambiente (PATH e LANGUAGE)

As variáveis de ambiente são "atalhos" globais que o sistema usa para funcionar. No Linux, elas são escritas em maiúsculas e acessadas com o símbolo `$`.

* **PATH:** Define em quais pastas o Linux deve procurar um comando quando você o digita. Se um programa não estiver no PATH, o terminal dirá que o comando não existe.
* *Exemplo:* `echo $PATH`


* **LANGUAGE / LANG:** Define o idioma das mensagens e menus do sistema.
* *Exemplo:* `echo $LANGUAGE` (mostra se o sistema está em `pt_BR`, `en_US`, etc).



### Exemplos de Prática:

1. **Ver caminho de execução:** `echo $PATH`
2. **Ver idioma configurado:** `echo $LANG`
3. **Criar variável temporária:** `CURSO="Redes"` e depois `echo $CURSO`
4. **Consultar histórico:** Digite `history` para ver o que você já fez.
