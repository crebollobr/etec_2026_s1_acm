# Ambientes de Computação e Virtualização

Nesta aula, exploraremos como os sistemas operacionais interagem com o hardware e as diferentes camadas de abstração que permitem o funcionamento da nuvem e dos ambientes modernos de desenvolvimento.

---

## Teoria Detalhada

### 1. Sistemas Operacionais no Hardware (Bare Metal)
O termo **Bare Metal** (metal nu) refere-se à instalação de um sistema operacional diretamente no hardware físico, sem nenhuma camada de virtualização entre eles.
* **Funcionamento:** O sistema operacional tem controle total sobre os recursos físicos (CPU, RAM, Disco).
* **Exemplo:** O seu computador pessoal ou um servidor dedicado de alta performance.
* **Ferramenta:** Sistemas operacionais como **Debian Linux** ou **Windows Server** instalados diretamente no disco rígido da máquina.



### 2. Virtualização e Hipervisores
A virtualização permite que um único hardware físico seja dividido em múltiplos computadores virtuais independentes.
* **Hipervisor:** É o software "maestro" que gerencia e distribui os recursos físicos para as máquinas virtuais.
* **Tipos de Hipervisores:**
    * **Tipo 1 (Nativo):** Roda direto no hardware (ex: **VMware ESXi**, **Microsoft Hyper-V**).
    * **Tipo 2 (Hospedado):** Roda como um programa dentro de outro sistema operacional (ex: **Oracle VirtualBox**).

### 3. Máquinas Virtuais (VMs) e Contêineres
* **Máquinas Virtuais:** Simulam um computador completo, incluindo o hardware virtual e um sistema operacional inteiro (chamado de Guest OS).
    * **Ferramenta:** **Oracle VirtualBox**.
* **Contêineres:** São mais leves que as VMs. Eles compartilham o "cérebro" (Kernel) do sistema operacional hospedeiro, empacotando apenas o necessário para a aplicação rodar.
    * **Ferramenta:** **Docker**.



### 4. Orquestração
Quando temos centenas de máquinas virtuais ou contêineres rodando, precisamos de ferramentas para automatizar a criação, manutenção e o desligamento desses recursos.
* **Ferramenta:** **Kubernetes** (para contêineres) ou **VMware vCenter** (para máquinas virtuais).

## Prática: Preparação para Instalação de Sistema Operacional

Para a nossa atividade prática, utilizaremos a virtualização para criar um ambiente isolado. Seguiremos os pré-requisitos abaixo:

### Pré-requisitos
1.  **Espaço em Disco:** Verificar se o seu computador possui pelo menos **10GB de espaço livre** na unidade `C:`. Máquinas virtuais ocupam espaço físico no seu HD como se fossem arquivos grandes.
2.  **Software de Virtualização:** Verificar se o **Oracle VirtualBox** está instalado. Ele será o nosso Hipervisor de Tipo 2.
3.  **Imagem do Sistema (ISO):** Realizar o download do **Ubuntu Server**.

> **Nota importante:** O **Ubuntu Server** é escolhido para ambientes de servidor por ser muito mais leve, já que não possui interface gráfica (janelas, ícones e mouse). Todo o gerenciamento é feito via linha de comando. Para uso pessoal em computadores domésticos, utiliza-se o **Ubuntu Desktop**.
