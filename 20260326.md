# Notebook — Redes no Linux

Guia introdutório para aula prática sobre redes no Linux.

---

# Comandos principais

## Ver interfaces de rede

```
ip addr
```

Mostra:

- interfaces
- endereços IP
- estado (UP/DOWN)
- MAC address

---

## Ver tabela de rotas

```
ip route
```

Mostra:

- gateway padrão
- redes locais
- rotas configuradas

Pergunta:

Qual é o gateway da máquina?

---

## Ver conexões abertas

```
ss -na
```

Mostra:

- conexões TCP
- conexões UDP
- portas abertas

---

## Ver serviços escutando portas

```
ss -ltpn
```

Mostra:

- portas TCP abertas
- processo responsável
- PID

Pergunta:

Qual serviço está rodando na porta 22?

---

# Configuração de rede (temporária)

Subir interface

```
sudo ip link set eth0 up
```

Adicionar IP

```
sudo ip addr add 192.168.1.100/24 dev eth0
```

Remover IP

```
sudo ip addr del 192.168.1.100/24 dev eth0
```

Observação:

Essas alterações não são permanentes.

# Firewalls no Linux

Linux possui três principais ferramentas.

---

## UFW

Firewall simplificado.

Ver status:

```
sudo ufw status
```

Ativar firewall:

```
sudo ufw enable
```

Liberar SSH:

```
sudo ufw allow 22
```

Liberar HTTP:

```
sudo ufw allow 80
```

---

## IPTABLES

Firewall tradicional do Linux.

Listar regras:

```
sudo iptables -L
```

Permitir SSH:

```
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
```

Bloquear porta 80:

```
sudo iptables -A INPUT -p tcp --dport 80 -j DROP
```

---

## NFTABLES

Firewall moderno substituto do iptables.

Listar regras:

```
sudo nft list ruleset
```

---

# Comparação

| Ferramenta | Nível |
|-----------|------|
| ufw | fácil |
| iptables | intermediário |
| nftables | avançado |
