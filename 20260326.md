
# 🐧 Linux Essencial e Shell Scripting

## 📅 Aula 01: Sobrevivência em Redes e Gerenciadores de Pacotes

Um bom profissional de TI precisa saber testar a conectividade e instalar ferramentas quando chega em um servidor "pelado". Vamos aprender os comandos básicos para isso.

### 📖 Teoria (1 hora)

#### 1. Ferramentas de Rede Essenciais
* **`ip addr`:** Mostra os endereços IP (o "RG" na rede) de todas as suas placas de rede (físicas ou virtuais).
* **`ping`:** Testa se outro computador está vivo. Ele envia pacotes "Echo" e espera o retorno.
* **`wget`:** Um "baixador" de arquivos. Você dá o link de um arquivo na internet e ele faz o download direto para a sua pasta atual.
* **`curl`:** Parecido com o wget, mas é focado em interagir com aplicações e APIs. Ele pega o conteúdo de um site e cospe direto na tela do terminal.
* **`ssh` (Secure Shell):** É o controle remoto seguro. Permite que você abra um terminal de outro computador pela rede, com tudo criptografado.

#### 2. Gerenciadores de Pacotes (O Mundo Ubuntu/Debian)
Como instalamos programas no Linux? Não baixamos ".exe" clicando em "Avançar".
* **Repositórios:** São como as "App Stores" oficiais do Linux. São servidores gigantes na internet cheios de programas testados e seguros.
* **Pacotes:** O programa em si (empacotado com tudo o que ele precisa para rodar).
* **APT:** É a ferramenta do Ubuntu que vai até o repositório, busca o pacote e instala para você.
* **Permissão:** Como a instalação mexe no sistema todo, **somente o usuário `root`** (administrador) pode instalar pacotes. Por isso usamos o `sudo` antes dos comandos.

### 💻 Laboratório Prático 01 (1 hora)

Vamos testar os comandos de rede e brincar com a loja de aplicativos do Linux.

**Passo 1: Reconhecimento de Rede**
1. Descubra o IP do nosso servidor:
   ```bash
   ip addr
   ```
2. Teste a conexão com o Google enviando apenas 4 pacotes (para não ficar infinito):
   ```bash
   ping -c 4 google.com
   ```
3. Use o `curl` para consultar uma API pública de clima. Ele vai trazer a previsão do tempo direto no texto!
   ```bash
   curl wttr.in/Campinas
   ```

**Passo 2: Gerenciando Pacotes**
Imagine que precisamos usar o `ping`, mas não sabemos qual pacote o instalou.

1. Pesquise no sistema qual pacote é o "dono" do comando ping:
   ```bash
   which ping
   dpkg -S bin/ping
   ```
   *(Resposta esperada: Ele dirá que pertence ao pacote chamado `iputils-ping`).*
2. Pesquise esse pacote no repositório do Ubuntu para ver os detalhes:
   ```bash
   apt search iputils-ping
   ```
3. Instale o pacote (ou atualize-o, caso já esteja instalado). Lembre-se do `sudo`!
   ```bash
   sudo apt install iputils-ping
   ```
