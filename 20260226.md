
#  Filtros, Pesquisa, Empacotamento e Montagem

Nesta aula, focamos em ferramentas de manipulação de dados, busca no sistema, edição de arquivos via terminal e gerenciamento de armazenamento.

---

## 1. Filtros e Visualização (`head` e `tail`)

Comandos essenciais para ler partes de arquivos grandes sem sobrecarregar a memória.

* **`head`**: Exibe o início do arquivo.
* **`tail`**: Exibe o final do arquivo.

```bash
# Exibir as primeiras 10 linhas de um arquivo
head arquivo.txt

# Exibir as últimas 20 linhas de um log
tail -n 20 sistema.log

# Monitorar um log em tempo real (muito usado por SysAdmins)
tail -f /var/log/syslog

```

---

## 2. Pesquisa de Arquivos (`find`)

O `find` percorre a árvore de diretórios para localizar arquivos baseados em diversos critérios.

```bash
# Buscar um arquivo pelo nome no diretório atual (.)
find . -name "documento.pdf"

# Buscar diretórios (type d) que começam com "projeto"
find /home -type d -name "projeto*"

# Buscar arquivos maiores que 50MB
find /var/log -size +50M

```

---

## 3. Filtragem de Texto e Padrões (`grep`)

O `grep` busca por strings ou expressões regulares dentro de arquivos ou fluxos de dados.

| Opção | Descrição |
| --- | --- |
| `-i` | Ignora o case (maiúsculas/minúsculas) |
| `-v` | Inverte a busca (mostra o que **não** coincide) |
| `-r` | Busca recursiva em pastas |
| `-n` | Mostra o número da linha |

```bash
# Filtrar uma palavra específica em um arquivo
grep "ERROR" logs.txt

# Listar processos e filtrar por um nome específico (ex: python)
ps aux | grep python

```

---

## 4. Comparação de Arquivos (`diff`)

Analisa as diferenças linha por linha entre dois arquivos.

```bash
# Comparar a versão 1 com a versão 2 de um script
diff script_v1.sh script_v2.sh

```

---

## 5. Empacotamento e Compressão (`tar`)

O comando `tar` é usado para agrupar arquivos (fita/archive) e, opcionalmente, comprimi-los usando `gzip` (`-z`) ou `bzip2` (`-j`).

```bash
# Criar um pacote comprimido (.tar.gz)
# c = create, z = gzip, v = verbose, f = file
tar -zcvf backup.tar.gz /caminho/da/pasta

# Extrair um pacote
# x = extract
tar -zxvf backup.tar.gz

```

---

## 6. Montagem de Dispositivos (`mount`)

No Linux, dispositivos físicos (pendrives, HDs) precisam ser "montados" em um ponto do sistema de arquivos.

```bash
# Listar discos e partições disponíveis
lsblk

# Montar uma partição em uma pasta específica
sudo mount /dev/sdb1 /mnt

# Desmontar o dispositivo (importante antes de remover o hardware)
sudo umount /mnt

```

---

## 7. Download de Arquivos (`wget`)

Uma ferramenta robusta para baixar conteúdos da web diretamente pelo terminal.

```bash
# Baixar um arquivo de um link
wget https://exemplo.com/arquivo.zip

# Baixar e salvar com um novo nome
wget -O instalador.sh https://link-do-site.com/s123

```

## 8. Editor de Texto (`vim`)

O `vim` é um editor poderoso e onipresente em servidores Linux. Ele funciona através de **modos**.

### Comandos de Navegação e Edição (Modo Normal)

* `i` : Entra no **Modo de Inserção** (para escrever).
* `ESC` : Volta para o **Modo Normal**.
* `x` : Deleta o caractere sob o cursor.
* `dd` : Deleta a linha inteira.
* `yy` : Copia a linha (yank).
* `p` : Cola (paste).
* `u` : Desfaz a última ação (undo).

### Comandos de Saída (Modo de Comando - Digite `:`)

| Comando | Ação |
| --- | --- |
| `:w` | Salva o arquivo (write) |
| `:q` | Sai do Vim (quit) |
| `:wq` | Salva e sai |
| `:q!` | Sai forçado sem salvar |
