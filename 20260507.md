
# 📓 Notebook: Configuração Completa Alpine Linux (SSH + XFCE via RDP)

**Pré-requisito:** Alpine Linux já instalado e com acesso à internet (comandos executados inicialmente no console da VM).
**Cenário:** A máquina virtual está com as portas mapeadas (Porta local 2222 -> Porta VM 22 | Porta local 33891 -> Porta VM 3389).

## Passo 1: Instalação do SSH e Criação de Usuário
Por padrão, o Alpine não vem com o servidor SSH habilitado para acesso externo. Vamos instalá-lo e criar nosso usuário padrão de acesso.

```bash
# 1. Instalar o servidor SSH (OpenSSH)
apk add openssh

# 2. Habilitar o serviço para iniciar com o sistema e iniciar agora
rc-update add sshd
rc-service sshd start

# 3. Criar o usuário "aluno" (o sistema pedirá para você digitar uma senha duas vezes)
adduser aluno
```

## Passo 2: Conectando via SSH e Escalonando Privilégios
Agora que o SSH está rodando e o usuário existe, você pode minimizar a tela da máquina virtual e usar o seu próprio terminal do Windows (Prompt de Comando ou PowerShell).

**Comando no Windows:**
```bash
ssh -p 2222 aluno@127.0.0.1
```
*Dica: Aceite a chave digitando `yes` na primeira conexão e insira a senha do usuário `aluno`.*

**Escalonando para Root (Superusuário):**
Para continuar instalando os programas via SSH, precisamos virar root.
```bash
su -
```
*(Digite a senha do root que você configurou durante a instalação do Alpine).*

📸 **Ação (Printscreen do SSH):** Neste momento, tire um printscreen da sua tela preta do CMD mostrando que você logou como `aluno` e depois rodou o `su -`.

## Passo 3: Instalando a Pilha Gráfica Completa (RDP + XFCE)
O segredo do Alpine é que a interface gráfica é modular. Precisamos instalar não apenas o XRDP, mas o servidor de vídeo (Xorg), a placa de vídeo virtual (Xvfb), a interface gráfica (XFCE) e o barramento de comunicação (D-Bus).

```bash
# Instalando todos os pacotes necessários de uma só vez
apk add xrdp xorg-server xfce4 xfce4-terminal xorgxrdp xvfb dbus dbus-x11 ttf-dejavu
```

## Passo 4: Configuração e Correção de Permissões do RDP
O Alpine é um sistema focado em segurança, então o ambiente gráfico bloqueia usuários comuns por padrão. Vamos aplicar as correções (vacinas) para evitar a famosa "tela preta".

```bash
# 1. Permitir que qualquer usuário inicie o servidor X11
echo "allowed_users=anybody" > /etc/X11/Xwrapper.config

# 2. Gerar o ID da máquina para evitar travamentos do D-Bus
dbus-uuidgen > /var/lib/dbus/machine-id

# 3. Criar o arquivo de inicialização do XFCE para o usuário 'aluno'
# (Este comando roda como usuário aluno para garantir as permissões corretas)
su - aluno -c 'echo "exec dbus-launch --exit-with-session startxfce4" > ~/.xsession'

# 4. Habilitar e iniciar os serviços de comunicação e RDP
rc-update add dbus
rc-service dbus start

rc-update add xrdp
rc-service xrdp start
rc-service xrdp-sesman start
```

## Passo 5: Conectando via RDP (Área de Trabalho Remota)
Agora o servidor está pronto para receber a conexão gráfica.

1. No Windows, abra o aplicativo **Conexão de Área de Trabalho Remota** (mstsc.exe).
2. No campo "Computador", digite: `127.0.0.1:33891`
3. Clique em **Conectar**.
4. Aceite o aviso de certificado (pode marcar a caixa para não perguntar novamente).
5. Na tela azul/cinza do XRDP, insira:
   * **Username:** aluno
   * **Password:** (senha do aluno)
   * *Atenção: Nunca use o usuário root aqui!*

## Passo 6: Instruções para o Printscreen do RDP
Ao conectar, o RDP pode abrir em **Tela Cheia**, o que esconde a sua barra de tarefas do Windows e dificulta o uso de ferramentas de captura.

**Como tirar o printscreen corretamente se estiver em Tela Cheia:**
* **Opção 1 (Teclado):** Pressione a tecla `Print Screen` (ou `PrtScn`) no seu teclado. O Windows copiará a imagem para a área de transferência. Você pode abrir o Paint ou o Word e dar `Ctrl + V` para colar.
* **Opção 2 (Barra Fixa):** Leve o mouse até o **topo central da tela**. Uma barra azul de conexão vai descer. Clique no ícone de "Restaurar Abaixo" (dois quadradinhos) para tirar o RDP da tela cheia e transformá-lo em uma janela. Em seguida, use a ferramenta de captura do Windows (`Win + Shift + S`).
* **Opção 3 (Atalho):** Pressione `Ctrl + Alt + Break` (se o seu teclado tiver a tecla Break/Pause) para alternar instantaneamente entre tela cheia e janela.

📸 **Ação (Printscreen do RDP):** Após acessar a interface com o ratinho do XFCE, tire o seu printscreen para validar o sucesso da configuração.
