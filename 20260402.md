## 📅  A Magia do Shell Scripting

**O grande segredo do Shell Scripting é:** *Qualquer comando que você digita no terminal pode ser colocado dentro de um arquivo de texto. Quando você roda esse arquivo, o Linux digita tudo sozinho para você, na velocidade da luz!*

### 📖 Teoria (1 hora)

* **Variáveis:** São "caixinhas" na memória do computador onde guardamos informações. No Linux, criamos variáveis sem espaços (Ex: `NOME="Maria"`) e lemos o que tem dentro delas usando um cifrão (Ex: `echo $NOME`).
* **Shebang (`#!`):** É a primeira linha obrigatória do seu script (Ex: `#!/bin/bash`). Ela avisa ao sistema: *"Ei, por favor, leia as instruções deste arquivo usando o idioma do Bash"*.
* **Permissão de Execução:** Quando criamos um arquivo de texto, ele é apenas texto. Para o Linux tratar ele como um programa, precisamos dar a permissão de execução com o comando `chmod +x`.
* **Argumentos:** São valores que você passa para o script na hora de rodá-lo (Ex: `./meu_script.sh Maria`). Dentro do script, o primeiro argumento vira a variável `$1`, o segundo vira `$2`, e assim por diante.

### 💻 Laboratório Prático 02 (1 hora)

Vamos provar que tudo no terminal pode virar um script automatizado!

**Passo 1: Testando Variáveis "Ao Vivo" no Terminal**
Antes de criar o script, vamos testar a lógica direto na linha de comando.
1. Crie uma variável chamada `a` com o valor 1:
   ```bash
   a=1
   ```
2. Use o comando `let` para fazer uma operação matemática (somar a variável com ela mesma):
   ```bash
   let a=a+a
   ```
3. Veja o resultado na tela (Lembre-se do `$` para ler a variável):
   ```bash
   echo $a
   ```
   *(Deve aparecer 2).*

**Passo 2: Automatizando (Criando o Script)**
Agora vamos transformar isso num programa real que aceita argumentos.

1. Crie e abra um arquivo chamado `calculadora.sh` usando o editor `nano`:
   ```bash
   nano calculadora.sh
   ```
2. Digite o seguinte código dentro dele:
   ```bash
   #!/bin/bash
   
   # Pegamos o valor passado pelo usuário ($1) e guardamos na variável 'a'
   a=$1
   
   echo "Voce me passou o numero: $a"
   
   # Fazemos a matematica
   let a=a+a
   
   echo "O dobro desse numero é: $a"
   ```
3. Salve e saia (No nano: `Ctrl+O`, `Enter`, `Ctrl+X`).

**Passo 3: Dando Vida ao Script**
1. Tente executar o arquivo agora:
   ```bash
   ./calculadora.sh 5
   ```
   *(Vai dar erro de permissão negada! Ele ainda é só um texto).*
2. Dê a permissão de execução:
   ```bash
   chmod +x calculadora.sh
   ```
3. Rode novamente, agora passando um número (Argumento 1) ao lado:
   ```bash
   ./calculadora.sh 5
   ./calculadora.sh 50
   ```
