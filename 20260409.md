# 📘 Minicurso: Fundamentos de Bash Scripting

**Bem-vindo(a) ao minicurso de Bash!** O Bash (Bourne Again Shell) é o interpretador de comandos padrão da maioria das distribuições Linux. Neste material, vamos aprender a criar scripts inteligentes que tomam decisões, repetem tarefas e organizam o código.

## ⚙️ O Básico: Shebang e Execução

Todo script Bash deve começar com a linha abaixo. Ela diz ao sistema qual interpretador usar:

```bash
#!/bin/bash
```

Para rodar um script no terminal, você precisa dar permissão de execução e depois chamá-lo:

```bash
chmod +x meu_script.sh
./meuscript.sh
```

## 🟢 Módulo 1: Tomada de Decisão (Condicionais)

O Bash toma decisões avaliando se um comando teve sucesso (código `0`) ou falhou (códigos `1` a `255`).

### 1.1 O comando `test` e o "If Antigo" `[`

O comando `[` era um atalho para o comando `test`. Os espaços ao redor dos colchetes são **obrigatórios**. O comando `[` atual é um recurso embutido do Bash, mas funciona do mesmo modo.

Podemos verificar o manual do `test`:
```bash
man test
```

Para obter ajuda dos comandos internos do Bash, usamos o comando `help`:
```bash
help [
```

**Exemplos de uso:**
```bash
# Usando o comando test
if test 10 -gt 5; then
    echo "10 é maior que 5"
fi

# Usando [ ] (If antigo)
if [ 10 -gt 5 ]; then
    echo "10 é maior que 5 usando colchetes"
fi
```

### 1.2 O "If Novo" `[[ ]]`

Mais moderno, seguro e com suporte a operadores lógicos avançados (`&&` para E, `||` para OU). Sempre prefira usar `[[ ]]`.

Para obter ajuda sobre ele, usamos:
```bash
help [[
```

**Exemplo de uso:**
```bash
nome="Linux"

if [[ $nome == "Linux" && 1 -eq 1 ]]; then
    echo "Nome correto e a matemática funciona!"
fi
```

### 1.3 Números vs Strings

O Bash usa operadores diferentes para comparar textos e números. Isso é vital! O interpretador precisa saber se você está avaliando "letras" ou "valores matemáticos".

**Testando Strings:** (`==` igual, `!=` diferente, `-z` vazia)
```bash
senha=""

if [[ -z $senha ]]; then
    echo "Erro: A senha está vazia!"
elif [[ $senha != "123" ]]; then
    echo "Erro: Senha incorreta."
else
    echo "Acesso liberado."
fi
```

**Testando Números:** (`-eq` igual, `-ne` diferente, `-gt` maior, `-lt` menor)
```bash
idade=18

if [[ $idade -ge 18 ]]; then
    echo "Maior de idade."
else
    echo "Menor de idade."
fi
```

> **⚠️ Por que não usar `==` para números no `[[ ]]`?**
> Veja a diferença de interpretação do Bash:
> ```bash
> valor="010"
> 
> # Comparação de TEXTO: "010" é diferente de "10"
> if [[ $valor == "10" ]]; then
>     echo "Texto igual"
> else
>     echo "Texto diferente"
> fi
> 
> # Comparação de NÚMERO: Matematicamente, 010 é igual a 10
> if [[ $valor -eq 10 ]]; then
>     echo "Valor numérico igual"
> fi
> ```

### 1.4 A "Mágica" da Matemática: `(( ))`

Se você acha difícil decorar siglas como `-gt` ou `-le`, o Bash oferece um contexto exclusivamente aritmético usando parênteses duplos `(( ))`. Aqui, você pode usar a matemática tradicional (`<`, `>`, `<=`, `==`).

```bash
idade=20

# Muito mais natural para quem já programa em outras linguagens:
if (( idade >= 18 )); then
    echo "Você é maior de idade!"
fi
```

### 1.5 Testando Arquivos e Diretórios

Perfeito para criar scripts de backup ou instalação.
* `-e`: O arquivo existe?
* `-f`: É um arquivo comum?
* `-d`: É um diretório?

```bash
if [[ -d "/etc" ]]; then
    echo "O diretório /etc existe no sistema."
fi
```

## 🔵 Módulo 2: Laços de Repetição (Loops)

### 2.1 O laço `while` e operações com `let`

O `while` roda enquanto uma condição for verdadeira. Usamos o `let` para fazer contas matemáticas simples (como incrementar nosso contador).

```bash
contador=1

while [[ $contador -le 3 ]]; do
    echo "Execução número: $contador"
    let contador=contador+1  # ou let contador++
done
```

### 2.2 O laço `for ... in` e o poder do Globbing (`*.txt`)

O `for` passa por cada item de uma lista. Podemos usar isso junto com a expansão de arquivos do Bash (Globbing) para processar vários arquivos de uma vez.

```bash
# Criando arquivos de teste rapidamente
touch arq1.txt arq2.txt foto.jpg

# Iterando apenas sobre os .txt
for arquivo in *.txt; do
    echo "Processando documento: $arquivo"
done

# Limpando a sujeira do teste
rm arq*.txt foto.jpg
```

## 🟣 Módulo 3: Organizando o Código (Funções)

Funções agrupam comandos sob um único nome. No Bash, você passa parâmetros para a função do mesmo jeito que passa para um script: usando `$1`, `$2`, etc.

> **Dica de ouro:** Sempre use a palavra `local` ao criar variáveis dentro de uma função, para que elas não vazem e afetem o resto do seu script.

```bash
# 1. Declarando a função
fazer_backup() {
    local arquivo_origem=$1
    local destino="${arquivo_origem}.bak"
    
    if [[ -f $arquivo_origem ]]; then
        cp "$arquivo_origem" "$destino"
        echo "[OK] Backup do $arquivo_origem criado com sucesso!"
    else
        echo "[ERRO] Arquivo $arquivo_origem não encontrado."
    fi
}

# Criando um arquivo de teste
touch meus_dados.txt

# 2. Chamando a função (passando parâmetros sem parênteses!)
fazer_backup "meus_dados.txt"
fazer_backup "arquivo_fantasma.txt"

# Limpando a sujeira do teste
rm meus_dados.txt*
```

```bash
#!/bin/bash

# Função que adiciona o prefixo 'processado_' ao nome do arquivo
renomear_arquivo() {
    local arquivo_atual=$1
    local novo_nome="processado_${arquivo_atual}"
    mv "$arquivo_atual" "$novo_nome"
    echo " -> Arquivo renomeado para: $novo_nome"
}

# === Script Principal ===
diretorio_alvo="./dados_teste"

# Criando ambiente de teste
mkdir -p "$diretorio_alvo"
touch "$diretorio_alvo/relatorio1.txt" "$diretorio_alvo/relatorio2.txt"

echo "=== Iniciando Processamento ==="

if [[ -d $diretorio_alvo ]]; then
    cd "$diretorio_alvo" || exit 1
    
    # Loop em todos os .txt
    for arquivo in *.txt; do
        if [[ -f $arquivo ]]; then
            echo "Encontrado: $arquivo"
            renomear_arquivo "$arquivo"
        fi
    done
    
    cd ..
else
    echo "Erro: O diretório $diretorio_alvo não existe."
fi

echo "=== Fim do Processamento ==="

# Limpando ambiente (opcional para testes)
rm -r "$diretorio_alvo"
