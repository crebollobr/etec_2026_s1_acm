

# 🐚 Aula de Shell Scripting: Do Zero ao Automação

## ⚙️ O Básico: Shebang e Execução

Todo script Bash deve começar com a linha abaixo. Ela diz ao sistema qual interpretador usar:

```bash
#!/bin/bash
```

Para rodar um script no terminal, você precisa dar permissão de execução e chamá-lo:
```bash
chmod +x meu_script.sh
./meuscript.sh
```

## 🟢 Módulo 1: Tomada de Decisão (Condicionais)

### 1.1 O comando `test` e o `[[ ]]`
O Bash evoluiu do comando `test` (ou `[ ]`) para o moderno `[[ ]]`. **Sempre prefira `[[ ]]`**, pois ele é mais seguro e aceita operadores lógicos como `&&` (E) e `||` (OU) sem erros estranhos.

### 1.2 Números vs Strings (O erro clássico)
O Bash diferencia a comparação de texto da comparação matemática. 
* **Strings:** `==`, `!=`, `-z` (vazia).
* **Números:** `-eq` (equal), `-ne` (not equal), `-gt` (greater than), `-lt` (less than).

### 1.3 A Mágica do `(( ))`
Para quem vem de linguagens como C, Java ou Python, o Bash oferece o contexto aritmético. Aqui você usa os símbolos matemáticos tradicionais:
```bash
if (( idade >= 18 )); then echo "Maior de idade"; fi
```

## 🔵 Módulo 2: Laços de Repetição (Loops)

### 2.1 O laço `while`
Roda enquanto uma condição for verdadeira. Útil para contadores ou monitoramento de processos.
```bash
contador=1
while [[ $contador -le 3 ]]; do
    echo "Rodada $contador"
    let contador++
done
```

### 2.2 As Faces do `for`
Existem várias formas de iterar no Bash, dependendo do seu objetivo:

1.  **Globbing (Arquivos):** `for arq in *.txt` (O melhor para manipular arquivos).
2.  **Sequência Brace `{}`:** `for i in {1..5}` (Rápido e limpo).
3.  **Estilo C:** `for ((i=0; i<5; i++))` (Controle total de incremento).
4.  **Lista Explícita:** `for item in "Servidor1" "Servidor2"` (Para listas fixas).

---

## 🟣 Módulo 3: Funções e Escopo
Funções ajudam a não repetir código. 
* **Parâmetros:** Recebidos como `$1`, `$2`.
* **Escopo:** Use sempre `local` para que uma variável dentro da função não altere o resto do script acidentalmente.

## 🏆 Módulo 4: O Desafio Final (Análise)

Abaixo, analisamos o script que integra todo o conhecimento da aula.

### O Script de Processamento de Arquivos
```bash
#!/bin/bash

# Função: Renomeia o arquivo adicionando um prefixo
renomear_arquivo() {
    local arquivo_atual=$1
    local novo_nome="processado_${arquivo_atual}"
    mv "$arquivo_atual" "$novo_nome"
    echo " -> Arquivo renomeado para: $novo_nome"
}

# Principal
diretorio_alvo="./dados_teste"
mkdir -p "$diretorio_alvo"
touch "$diretorio_alvo"/relatorio{1,2}.txt

if [[ -d $diretorio_alvo ]]; then
    cd "$diretorio_alvo" || exit 1
    
    for arquivo in *.txt; do
        if [[ -f $arquivo ]]; then
            echo "Encontrado: $arquivo"
            renomear_arquivo "$arquivo"
        fi
    done
    cd ..
else
    echo "Erro: Diretório não encontrado."
fi
```
